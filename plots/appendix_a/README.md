# appendix_a

Two figures for Appendix A ("Recovery of non-periodic power spectra",
`app:recovery` in `tex/july_16_2026.tex`): Fig. A.1 (the three example
light curves) and Fig. A.2 (the beta=4 PSD recovery example). Regenerated
together 2026-07-23 because both existing figure files had gone stale --
they were either missing or built from data that predated the AR(1)
initialization bugfix (see
`code_backup/Claude_Beta_Recovery/CORRECTION_LOG_2026-07-21.md`).

## Question
What do the raw (pre-AR(1), pre-Poisson) colorednoise light curves used in
the Appendix A validation actually look like (Fig. A.1), and what does a
single-draw PSD recovery example look like end-to-end -- periodogram,
binning, fit, and comparison to the true input PSD -- for the beta=4 case
specifically discussed in the text (Fig. A.2)?

## Motivation
Both figures previously referenced by the paper (`app_A_light_curves.pdf`,
`app_A_fig_beta_4_v2.pdf`) were not resolving at compile time (not present
in `tex/`), and separately, this session's investigation found and fixed a
real bug in the AR(1) model's stationary-variance initialization
(`ar1_hmc_v2.py` replacing `simple_HMC.py`). Regenerating both figures
from the corrected model's T=1000 output ensures they reflect the current,
correct pipeline rather than stale or pre-bugfix output.

## Parameters
- beta_true: 1.7, 3.0, 4.0 (Fig. A.1, all three); 4.0 only (Fig. A.2)
- T = 1000, shift_term = 7.0 (matches the data already used for the T=500
  vs T=1000 comparison and the SNR sweep earlier this session)
- Model: `ar1_hmc_v2.py` (corrected AR(1)/HMC model, Table 6 priors)
- Fig. A.2 uses posterior draw index 0 as "one representative draw" --
  the fitted beta for this one draw (3.82) is expected to differ somewhat
  from Table A.1's median (which is computed across the full per-draw
  distribution, not one draw); this is stated explicitly in the figure's
  LaTeX caption. It happens to land close to Table A.1's current published
  median for beta=4 (3.83), which is a reassuring but incidental
  consistency check, not a guarantee that would hold for any draw index.
- Fig. A.2's periodogram / 9-bin / multi-start curve_fit methodology is
  copied verbatim from
  `code_backup/Claude_Beta_Recovery/Appendix_A/reproduction_2026-07-20/psd_beta_recovery_per_draw_binned_fit.py`
  (the canonical, already-reviewed script behind Table A.1) for
  consistency -- including its known cosmetic quirk where 1-2 binned
  points can show very large error bars (linearized log-space error
  propagation exaggerates the error when within-bin periodogram scatter
  is large relative to the bin mean, which is expected given periodograms
  are chi-squared(2)-distributed at each frequency).

`plot_light_curves.py` (Fig. A.1), `plot_psd_beta4_recovery.py` (Fig. A.2)

## Outcome
Fig. A.1: the three light curves become visibly smoother as beta
increases (1.7 -> 3 -> 4), consistent with more power at low frequencies
for steeper power-law indices. Fig. A.2: the single-draw periodogram, its
9-bin average, and the power-law-plus-constant fit (beta=3.82) all track
the true input colorednoise PSD's slope well at low-to-mid frequencies;
at high frequencies the AR(1) reconstruction's PSD flattens onto a noise
floor well above the true input's (which keeps falling), visually
illustrating the AR(1) model's fixed asymptotic slope-2 ceiling discussed
in sec. `verification_results_psd` ("The case for beta").

## LaTeX captions
```latex
% Fig. A.1
Visualisation of three light curves generated by the colorednoise code
each running for 1000 time steps. In each light curve the mean flux was
subtracted from the flux. The curves become progressively smoother as the
power law index increases which results in higher powers at lower
frequencies in the PSD plot (see fig. A.2).
```
```latex
% Fig. A.2
PSD recovery for a colorednoise realisation with true power-law index
$\beta = 4$. Black points show the unbinned periodogram of one
representative AR(1) posterior draw; orange points show the same
periodogram averaged into 9 logarithmically-spaced frequency bins, with
error bars from the scatter within each bin. The red dashed line is the
power-law-plus-constant fit (Eq.~\ref{eq:periodogram_fit}) to this single
binned draw, shown for illustration; the $\beta$ value reported in
Table~\ref{tab:appendix_params} is the median (with 5\%-95\% interval)
over the distribution of such fits across all posterior draws, not this
one realisation. The solid blue curve shows the periodogram of the true,
pre-AR(1) colorednoise input signal, for direct visual comparison against
the recovered fit.
```
